# PanDao — Grav CMS

Лёгкая PHP-CMS (flat-file, без базы данных) с админкой, SEO-блоком и формой заявок.
Здесь хранится **только авторская часть** (тема, страницы, конфиг). Ядро Grav качается
скриптом сборки — в репозиторий не коммитим (≈21 МБ).

## Что внутри
- `user/themes/pandao/` — тема: вёрстка лендинга (`templates/`), стили (`css/kit.css`,
  `colors_and_type.css`, `legal.css`), скрипты (`effects.js`, `site.js`, `icons.js`),
  картинки. `blueprints/default.yaml` добавляет в админке вкладку **«Контакты PanDao»**.
- `user/pages/` — `01.home` (лендинг + поля контактов + форма заявки) и 4 legal-страницы.
- `user/config/` — `site.yaml`, `system.yaml`, плагины `form` и `email`.

## Сборка пакета для Beget
```bash
bash scripts/build-grav.sh
# → ~/Downloads/pandao-grav-beget.zip
```
Скрипт скачивает ядро Grav + Admin, накладывает нашу тему/страницы/конфиг, убирает
тестовые данные и пакует zip.

## Деплой на Beget (shared)
1. В панели Beget выбери **PHP 8.2+** для домена.
2. Залей **содержимое** `pandao-grav-beget.zip` в `~/<домен>/public_html/`
   (чтобы `index.php` и `.htaccess` оказались в корне).
3. Открой `https://<домен>/admin` — Grav предложит создать аккаунт администратора.
4. Заявки с формы приходят на `pandaologistics@gmail.com` (плагин Email, движок
   `native`/PHP mail). Для надёжной доставки в админке → Plugins → Email можно включить
   **SMTP** с почтового ящика Beget. Все заявки также сохраняются в админке (Forms/Data).

## Что редактируется в админке
- **SEO** — заголовок и метатеги каждой страницы (вкладка Options/SEO).
- **Контакты** — телефон, почта, WhatsApp/Telegram, адрес, часы (вкладка «Контакты PanDao»
  на странице «Главная»).
- **Legal-страницы** — текст напрямую.
- Тексты секций лендинга (услуги, факты, FAQ) пока в шаблоне
  `templates/partials/landing.html.twig`. Их можно вынести в админ-поля отдельным шагом.

## Регенерация лендинга из React-исходников
`landing.html.twig` сгенерирован из компонентов `ui_kits/website/*.jsx` через
server-side рендер (React в Node) с заменой контактов на Twig-поля. Если меняется
дизайн в React-исходниках — повторить SSR и пересобрать партиал (см. историю в
`scripts/`). Для правок только текста/контактов этого не требуется.
